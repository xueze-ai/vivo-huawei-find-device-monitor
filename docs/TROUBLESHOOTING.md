# 故障排查

## 收到“登录失效”

停止对应监控容器，使用登录模式打开持久浏览器目录，完成网站要求的登录或验证，然后重新启动监控。不要把验证码发到日志或聊天中。

## 收到“位置获取失败”

依次检查：

1. 手机联网、定位服务和查找设备功能是否开启。
2. 网站页面是否改版，设备名称及 `Contacts` 文本是否与环境变量一致。
3. 容器能否访问 vivo、华为与 Server 酱域名。
4. `docker compose logs --tail=100 <服务名>` 中是否有选择器超时。

## 手机离线或位置未更新

这通常不是服务器故障。vivo 监控会保留最后一次有效位置，并把离线或数据过期作为独立状态通知。

## noVNC 无法连接

确认对应服务正在运行，且本地 SSH 隧道端口与 Compose 映射一致：

```bash
ssh -L 6080:127.0.0.1:6080 user@example-server
```

随后只在本机打开 `http://127.0.0.1:6080/vnc.html?autoconnect=true&resize=scale`。
